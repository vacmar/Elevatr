# Elevatr

Elevatr is a full-stack job and internship portal for students and recruiters.

## Stack

- Frontend: Next.js App Router + Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Auth: JWT in HttpOnly cookies
- Uploads: local storage in development, replaceable storage adapter for production

## Structure

- `backend/`: FastAPI app, API routes, services, schemas, and models
- `frontend/`: Next.js app, dashboards, and shared UI
- `docker-compose.yml`: local PostgreSQL and app orchestration
